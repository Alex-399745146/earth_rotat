# Вращение Земли в терминале

Интерактивная CLI-анимация вращения Земли на Python.

Приложение отображает ASCII-анимацию Земли в терминале, позволяет выбрать количество суток, скорость вращения и цвет изображения. Интерфейс реализован с помощью библиотеки Rich.

## Возможности

- ASCII-анимация вращения Земли в терминале
- Интерактивное русскоязычное меню
- Выбор количества суток вращения
- Настройка задержки между кадрами
- Выбор цвета анимации
- Режим без цветного вывода
- Отображение текущего дня и номера кадра
- Шкала общего прогресса от 0% до 100%
- Корректное завершение анимации по `Ctrl + C`

## Технологии

- Poetry

## Установка

Клонируйте репозиторий:

```bash
git clone [https://github.com/Alex-399745146/earth_rotat.git](https://github.com/Alex-399745146/earth_rotat.git)
cd earth_rotat
```

Установите зависимости через Poetry:

```bash
poetry install
```

## Запуск

Запустите приложение из корня проекта:

```bash
poetry run python -m earth_rotat.main
```

После запуска появится меню:

```text
1. Запустить анимацию
2. Справка
3. Выход
```

При запуске анимации можно настроить:

```text
Количество суток: 10
Задержка между кадрами: 0.08
Цвет: голубой
```

## Прогресс вращения

Один полный проход всех ASCII-кадров соответствует одним суткам вращения Земли.

Например, при выборе 10 суток:

```text
День 1 из 10 — около 10%
День 5 из 10 — около 50%
День 10 из 10 — 100%
```

Шкала прогресса обновляется во время анимации и показывает общий ход выполнения от 0% до 100%.

## Управление

- `Enter` — подтвердить значение или выбрать действие по умолчанию
- `1`, `2`, `3` — выбрать пункт меню
- `Ctrl + C` — остановить анимацию
- `3` в главном меню — корректно завершить программу
